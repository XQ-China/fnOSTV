# fnOSTV 1.0.5 · TextureView 播放层

个人自用的 Android 4.4 客户端修改版，基于 [XG-China/fnOSTV](https://github.com/XG-China/fnOSTV) 二次开发（MIT）。

## 处理

- 播放层从 `SurfaceView` 换成 `TextureView`，切后台不立刻销毁渲染表面，纹理留 60 秒
- 回前台按记录的位置重建播放器，不走「表面还在就直接 start」
- 位置三处兜底：切后台记一次、播放中每轮刷新、重建时取不到就退回上次记录
- 全程不放黑幕遮罩，只用文字提示，恢复期提示常驻不闪
- 选集补队列：首页、最近播放、详情页直接点播也会把当前条目补进播放列表，单集也能拉出面板并切换

## 实测

- 设备：荣耀 T1-821w 平板（Android 4.4.2 / 1280×800 / 2G 内存 / 麒麟 910）
- 1080P H.264 正常播放，切后台回来约 1–2 秒出画面
- 4K 转码流在 4.4 上软解跟不上，不作为可用场景

## 本版内容

- 界面：侧栏折叠（260dp ↔ 64dp）、媒体库横幅海报布局 + 文件夹角标、卡片标题；选集面板右侧竖排、当前集蓝框
- 手势：单击切控制条、双击暂停、左右滑 seek、长按 1.5x/2x 加速、左半屏竖滑亮度、右半屏竖滑音量、最右 0.5cm 静默区
- 交互：播放页跟随系统自动旋转开关、切后台自动暂停、回前台续播
